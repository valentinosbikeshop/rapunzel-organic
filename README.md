## 🚀 Características Principales

- **Arquitectura 100% Estática (Next.js 14 App Router):** Exportación SSG ultrarrápida, tiempos de carga instantáneos (LCP < 1.0s) y cero base de datos externa.
- **Carrito de Compras con Envío Directo a WhatsApp:** Las clientas pueden armar su bolsa, completar sus datos de envío para Santiago o Regiones (Starken) y despachar el pedido pre-formateado directamente al WhatsApp oficial (`+56 9 5367 2027`).
- **Diagnóstico Capilar Inteligente (Hair Quiz):** Test de 3 preguntas que diagnostica el estado del cuero cabelludo y recomienda la rutina botánica exacta con botón de adición directa a la bolsa.
- **Showcase de Video Vertical (Reels):** Integración nativa de videos 9:16 con transcripciones literales de clientas y testimonios reales.
- **Galería de Antes y Después:** Casos documentados de recuperación capilar en alopecia, postparto, déficit nutricional y línea masculina.
- **Diseño Móvil Primero (Mobile-First):** Sistema de diseño inspirado en la botánica chilena (`#5B6434`, `#9BA75A`, `#C87A38`, `#FBF9F7`), con micro-interacciones fluidas y tipografía editorial elegante (*Playfair Display* & *Plus Jakarta Sans*).

## 🛠️ Tecnologías Utilizadas

- **Framework:** Next.js 14 (App Router, Static Export)

- **Iconografía:** Lucide React
- **Animaciones:** Framer Motion
- **Despliegue:** Vercel Global Edge Network

## 📦 Ejecución Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/valentinosbikeshop/rapunzel-organic.git
cd rapunzel-organic

# 2. Instalar dependencias
npm install

# 3. Iniciar entorno de desarrollo
npm run dev

# 4. Compilar para producción
npm run build
```
